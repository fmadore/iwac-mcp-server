# v3.8.0 — Research selections and source-backed views

This release preserves research scope when moving from a chart to its sources,
reports incomplete searches explicitly, and adds a research workbench without
replacing the existing server architecture. See the
[workbench guide](../research-workbench.md) for examples and methods.

- **Correctness:** exact topic/tag drill-downs retain filters; grouped lunar data
  renders and opens the correct subset; failed full-text passes remain visible;
  strict date validation and partial-date overlap fix boundary errors; multi-start
  PCA fixes the orthogonal-seed counterexample; map sampling distinguishes capped,
  invalid and missing embeddings. Similarity uses cosine, including unnormalized
  stored vectors, and no longer labels a threshold as proof of a reprint.
- **Research workflow:** `explore_corpus` adds paginated sources, a reader,
  concordance, source/year coverage, two-selection comparisons, attention matrices
  and explicit authority-alias suggestions. Temporal tools expose normalized
  shares with their raw counts and denominators. Disagreement cells open sources;
  similarity results offer a candidate chronology.
- **Interaction:** stable IDs, Back, loading/error recovery, latest-request-wins
  rendering, keyboard activation and data-table alternatives. CSV/JSON/SVG exports
  preserve provenance; SVG exports include all panels and embedded styles.
- **Operations:** request-pinned dataset files, revision configuration and snapshot
  identities; fail-closed manifest recovery and cross-process writer exclusion;
  bounded queues, cancellation, PCA workers and bounded caches; authenticated
  process metrics. Immutable cache generations are retained, so operators must
  budget disk space and stop cache users before cleanup.
- **Embedding migration support:** model/field/dimension/revision contracts, an
  opt-in local embeddings adapter, and a relevance-evaluation script. Matching
  corpus regeneration and real-model evaluation are still required. The default
  provider and public corpus are unchanged.
- **Offline analysis:** a bounded exact-cosine candidate-generation script exports
  pairs, chronological source groups and input hashes for close reading.

Validation includes offline unit and MCP round trips, injected full-text failures,
request consistency during refresh, manifest recovery, a mock local embedding
provider, real-DOM SVG/keyboard navigation, both HTTP protocol eras and resource /
token budgets. Live public-corpus smoke tests, paid Gemini calls, actual desktop
host rendering and native Windows/macOS runs remain deployment/release checks.

## Review fixes folded into this release

v3.7.0 was prepared but never published, so its changes
([notes](v3.7.0.md)) ship in this release as well. A review of the server
after v3.6.0 added these fixes before tagging:

- **Private-mode coverage.** An instance reading the private full mirror no
  longer tells the model, in its handshake and research prompt, that it reads
  the public dataset with OCR for about half the articles. Public mode keeps
  its existing wording; the prompt's stale "~56% of articles" is gone.
- **Long transcriptions.** `get_audiovisual` returned transcriptions uncapped
  (one runs to ~470k characters) and now caps them like article OCR and takes
  a `keyword` for excerpts. All five `get_*` tools share one handler.
- **Configuration.** An optional extension setting left blank no longer
  arrives as a literal `${user_config.*}` string that passes for a token. HTTP
  mode refuses to serve the private mirror unless `IWAC_ALLOW_PRIVATE_HTTP=true`
  is also set, and both transports log which dataset they serve. A refused
  private-dataset token is reported as such instead of as an outage.
- **Charts.** Network nodes, map bubbles, country shapes and scatter dots are
  clickable again (they lacked the class the click handlers select, yet were
  keyboard-focusable). The lunar note no longer shows "Rabi&#39; I", the
  lexical button reads "Group by" again, subtitles are escaped, points outside
  the named groups are grey, and the country legend matches its bars.
- **Speed.** `get_sentiment_distribution` counts every label column in one
  pass (`model:"all"` with a subject filter 401 → 169 ms), and a keyword
  aggregate evaluates its full-text filter once rather than once per query
  (`get_field_distribution` with a keyword 2.2 → 0.85 s). Payloads are
  unchanged.
- **Tests.** Round-trip suites refuse a bundle older than its sources,
  worst-case token cases fail on empty results, and each suite has one
  failure counter.

Operators: a self-hosted HTTP instance that deliberately serves the private
mirror must now also set `IWAC_ALLOW_PRIVATE_HTTP=true`.
