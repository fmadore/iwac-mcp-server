# v5.0.0: one keyword rule, a stricter contract, attested releases

A major release because two behaviours change for existing callers: a
multi-word keyword now requires every word rather than one exact sequence, and
an unknown argument name is refused rather than ignored. Single-word keywords,
every tool name and every result shape are unchanged. Most of it carries over
what the AMIRA server already does well; the comparison of the two servers is in
the repository history of 28 October 2026.

## What changes for research

- **Every word must occur.** `search_articles`, `search_publications`,
  `search_references`, `search_documents`, `search_audiovisual`,
  `search_images`, `search_index`, every aggregate and the workbench now read
  `pèlerinage Mecque` as "both words, anywhere in the record", as the unified
  `search` always did. A `"quoted phrase"` must occur as written, and
  `keyword_mode: "literal"` restores the old single-substring match. Multi-word
  counts from earlier runs are not comparable; provenance reports
  `analysis_version: iwac-research-v3`.
- **Empty results explain themselves.** A filtered list with no match carries a
  `hint`; the article, publication and reference searches add `did_you_mean`
  with close stored `subject` and `newspaper` values ("Ramadhan" → "Ramadan").
- **Linked exports.** `explore_corpus` with `link: true` returns an
  `iwac://export/{mode}/{subset}/{selection}` resource link: the whole selection
  (up to 5,000 items) as one manifest, CSL-JSON or BibTeX file, with its
  manifest and provenance, instead of 50-item pages in the conversation.

## What changes for clients

- **Instructions fit 2,048 characters** in every mode, with the citation rule
  and the interpretive guardrails first. The 4,462-character text was cut by
  hosts; a test now holds every mirror, profile and semantic mode under the
  limit. Methods moved to the skill and the tool descriptions.
- **Strict inputs.** Every input schema is strict: a misspelt argument
  (`keywords` for `keyword`) is an error. Arguments are capped at 1,000 array
  elements and object members, and strings at 2,000 characters.
- **Coded errors.** Error bodies gain a stable `code` (`invalid_argument`,
  `not_found`, `unavailable`, `data_error`); `error` and its companions are
  unchanged.
- **Compact provenance.** The last text block now names the snapshot id,
  revision, access mode, the subsets read and their freshness when unverified:
  ~390 characters where the full record took ~2,350 on multi-subset calls. The
  full record stays in `_meta["islam.zmo.de/provenance"]`.
- **Pages stop at ~40,000 characters** with `response_limited: true` and an
  exact `next_offset`.
- **Tool profiles.** `IWAC_TOOL_PROFILE=core|analysis|search` registers a
  smaller surface. `search`, `fetch` and `get_collection_stats` carry
  `anthropic/alwaysLoad` for hosts that defer tool loading, and the tool title
  is no longer repeated in its annotations. The full footprint fell from 15,968
  to 15,685 tokens.
- **Loopback origins** (`localhost`, `127.0.0.1`, `[::1]`) reach the HTTP
  endpoint without an allowlist entry.
- **Prompt completion.** `iwac_research` completes its `depth` argument.

## Releases and CI

- Build-provenance attestations for both bundles, the skill zip, `server.json`
  and the image (`gh attestation verify …`).
- The Docker base image is pinned by digest and kept current by Dependabot,
  which never moves the Node major.
- CI audits runtime dependencies, runs the built bundle on Node 26 as well as
  the declared floor, sets a timeout on every job, and runs the official MCP
  conformance suite (2026-07-28 requirements) behind a token proxy, with a
  check-by-check baseline of fixture-only failures.
- New property-based tests (fast-check) on accent folding, excerpts, keyword
  terms and table-of-contents matching.
- `npm run set-version -- X.Y.Z` sets every version copy CI checks.
