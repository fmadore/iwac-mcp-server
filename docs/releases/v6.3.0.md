# v6.3.0: results that match what was asked

A minor release of fixes found in two code reviews of v6.2.0, each verified
against the code and the published parquet. They change what a researcher gets
back: false zero results, a selection wider than the one displayed, broken
citation links and wasted round trips. One exact field is added; no tool, argument
or result field is removed. The always-on footprint is unchanged at 15,723 of
16,000 tokens.

## Search follows the one keyword rule everywhere (#70)

- `search` now reads a "quoted phrase" as one term, as every other tool does.
  It used to split on spaces and keep the quotes in the pattern, so
  `"Ibrahim Niasse"` returned nothing. It also refuses a query of more than 12
  terms, like the other searches.
- A keyword that has text but no term, such as `""`, is refused with
  `invalid_argument`. It used to add no filter and return the whole subset while
  the echo still showed the keyword. A blank keyword still means "no keyword",
  and `search_index` keeps its documented rule that a blank keyword lists every
  entry.
- Exact filters are trimmed, so `subject: "   "` no longer matches the 1,700
  articles whose subject is empty.

## A topic is identified by its model as well as its id (#84)

On `references`, the French and English LDA models both number their topics
from 0. `get_topic_distribution` counted them apart, but clicking a topic, or
filtering by `topic_id`, selected both, and the comparison mode merged them.

- New exact field `topic_model` (the stored `lda_model_name`). `topic_id` alone
  behaves as before.
- When a result spans several models, each topic names its `topic_model` and a
  note says to select with both fields. Article results, which have one model,
  are unchanged.
- A click on a topic in the chart selects that topic in its own model.
- `explore_corpus` comparison groups topics by model and id, labels each cell
  `id: label`, and carries `topic_id` and `topic_model` for drill-down.

## Exports cite correctly (#69)

- BibTeX keeps `url` and `doi` as written. They used to be LaTeX-escaped, so
  every IWAC url (`afrique_ouest`) and 24 DOIs got a backslash in the link.
  Line breaks are still removed, and `{`, `}` and `\` are percent-encoded, so
  hostile metadata still cannot break out of the field.
- CSL-JSON exports the 114 theses and mémoires ("Thèse de doctorat",
  "Mémoire de maitrise", "Mémoire de licence") as `thesis`, with the stored
  label as `genre`; they used to fall back to `document`. Conference papers,
  book reviews, encyclopedia entries, blog posts and working papers get their
  CSL types too. BibTeX keeps theses as `@misc`.

## Publications (#71)

- `search_publications` measures its page budget after reducing each issue's
  table of contents to the matching entries. A 20-row keyword page used to
  stop after 5 to 7 rows.
- `get_publication_fulltext` returns the issue's canonical `url`, so a quoted
  issue can be cited.
- `iwac://export/...` resources apply the same input length limit as tool calls.
