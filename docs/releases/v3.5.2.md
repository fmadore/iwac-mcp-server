# v3.5.2

This maintenance release improves embedding validation and reorganizes the
server internals while preserving public tool names, input/output schemas,
registration order, and model/chart data separation.

- Share finite-vector validation and overflow-safe normalization between
  semantic search and semantic maps. Reject malformed and sparse vectors.
- Split shared tool helpers and aggregate tools into focused modules.
- Share typed payload contracts across all 14 charts and server result builders.
- Centralize offline test connections with cleanup on failure and coverage for
  protocol pinning and repeated cleanup.
- Include the upstream Gemini client and development-tooling updates.
- Refresh compatible transitive dependencies to address the `fast-uri` and `qs`
  audit findings.

The detailed implementation and verification history is in `REFACTORING.md`.

Validation: typecheck, lint, build, 112 unit tests, two lifecycle tests, and all
fixture, chart, skill, HTTP, and token-budget checks pass. Tool-definition token
footprint is unchanged; npm audit reports zero vulnerabilities.
