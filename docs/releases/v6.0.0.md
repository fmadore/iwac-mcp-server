# v6.0.0: Claude Haiku 5.5 joins the panel and becomes the default reader

A major release because one behaviour changes for existing callers: the
default sentiment model moves from `gpt-5-6-luna` to `claude-haiku-5-5`. Every
inline `polarity`, `centrality` and `subjectivity` value, the
`search_by_sentiment` filters, `get_country_comparison` and the semantic map's
`polarity` colour now report Haiku's reading. Tool names and result shapes are
unchanged, and each of these surfaces still names its model
(`sentiment_model`, `polarity_model`). Closes #58.

## Why Haiku is the default

Claude Haiku 5.5 joined the generation-2 panel on 2026-10-27 and is the only
member that has read the newest arrivals: it scores **16,617** of 16,715
articles, where Luna and three others stop at 12,298. Under Luna, every inline
label on the last ~4,400 articles was empty and the single-model tools left
them out. Haiku also reads the construct the way the panel does: it has the
highest mean polarity κ against the other five (0.499) and sits mid-panel on
centrality and subjectivity.

Two things to carry with it, which the payloads state:

- **4,366 articles have Haiku as their only rater.** They have no consensus
  (one vote is not a majority) and sit outside every all-model agreement base,
  so a default figure that leans on recent material leans on one model.
- **No pilot.** Haiku was promoted without one, so no self-consistency figure
  covers it yet.

An inline figure quoted from an earlier run is Luna's. Restate it rather than
comparing it with a current one, or ask for `model="gpt-5-6-luna"` explicitly.

## The six-model panel

- **`claude-haiku-5-5` is served everywhere a model is**, with the aliases
  `claude`, `anthropic` and `haiku`. Its `model_caveat` and
  `agreement.base_caveats` entry disclose the single-rater articles.
- **`model="all"`** now reports six models and fifteen pairwise counts.
  Unanimity on polarity is 30% (3,632 of the 12,098 articles all six scored),
  down from 32% with five; the base is still capped by Qwen.
- **The chart captions coverage both ways.** Rings are compared with the
  panel's usual coverage (12,298), so Qwen reads "200 fewer articles scored"
  and Haiku "4,319 more", instead of five rings captioned as short.

## The consensus follows the panel

- **The server reads the `consensus_g2_*` columns.** Upstream moved the
  panel majority there when Haiku joined and cleared the legacy `consensus_*`
  columns, so the consensus had shrunk to 37 articles and the weekly live check
  failed. It now covers 10,463 articles on polarity, 10,995 on centrality and
  12,078 for the subjectivity median.
- **`instrument_ids`** names the fingerprint of the panel and rule behind each
  consensus row, so a five-voter majority can be told from a six-voter one.
- **An empty consensus** now reads as "no majority, or fewer than two votes".
  With six voters a 3 to 3 split is a tie, which is most of why the disputes
  rose (polarité 1,835, centralité 1,303, subjectivité 4,247).

Dataset revisions pinned before 2026-10-27 have no `consensus_g2_*` columns, so
the consensus reports as absent there.
