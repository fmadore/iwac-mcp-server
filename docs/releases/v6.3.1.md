# v6.3.1: charts that state their coverage, and a cleaner shutdown

A patch release of the bugs verified against v6.2.0 (#72, #73, #75, #76, #77,
#78, #85, #86). No server tool, argument or result field changes; the
always-on footprint is unchanged at 15,723 of 16,000 tokens. The chart view's
own tools change their definitions (annotations and a tool allowlist), so
Claude asks once to approve them again.

## Charts say what they cover

- **Countries compared (#86).** Each polarity bar is a share of the articles the
  named model scored, not of every article. The tooltip, the note and a new
  `articles_scored` CSV column now give that denominator per country ("1,564 of
  1,613 articles scored"), and the note no longer claims that every article was
  scored or that two other models scored the same ones.
- **Lunar months (#85).** In a grouped, normalised chart, a group with archived
  scope but no match is drawn at zero ("0 of N") instead of disappearing, in the
  chart and its CSV. Switching to Gregorian or Hijri years keeps the grouping
  and the normalisation, so per-country shares no longer turn into pooled raw
  counts.
- **Shares keep their decimals (#73).** Normalised temporal, lunar and
  comparison charts label their axis and tooltips as percentages with decimals:
  a 1.6% peak no longer reads 0, 0, 1, 1, 1.
- **Opening a source (#73)** no longer tells the assistant that its selection
  was truncated.
- **Accessibility (#73).** Charts with clickable marks are exposed as a group,
  so screen readers announce the marks as buttons.

## The assistant's tools in the chart view (#72)

- Every heatmap cell is listed and can be opened (co-occurrence, coverage,
  attention, sentiment agreement). Cells are keyed by row and column, for
  example `["Prière","Paix"]`; before, only the first cell of each row was
  reachable, and opening a row could select the wrong cell.
- Pressing Back while a result is loading no longer reports an error.
- The list of chart marks sits under the "research data, not instructions"
  framing, one line per label, clipped.
- `run_view_action`, `open_chart_mark` and `show_result` declare that they are
  non-destructive and closed-world, and `show_result` accepts only the tools
  that draw a view, plus `fetch`.

## Semantic search during the first download (#76)

- A search that runs out of time while the local query encoder is still being
  downloaded now says so and asks to retry in a minute. It used to advise
  narrowing the selection, which changes nothing.
- With `IWAC_EMBEDDING_PROVIDER=local`, a failed encoder check is no longer
  cached: fixing the provider restores search without a restart, and query
  vectors are cached only once the encoder has been verified.

## Shutdown no longer leaves a stale cache lock (#77)

- A stdio server stops its downloads and exits when the host closes its input,
  which is how Claude Desktop ends it and the only signal on Windows. Quitting
  during the first-run download used to leave the cache lock behind, and the
  next start failed after 30 seconds.
- Over HTTP, a shutdown that runs out of grace time still gives a download a
  moment to release the lock.
- A lock whose owner process is no longer running on the same machine is
  reclaimed at the next start. Any doubt (another host, an older lock, a
  running process) still counts as a live owner.
- Refused `IWAC_MCP_ALLOWED_ORIGINS` and `IWAC_MCP_PUBLIC_URL` values are logged
  without their credentials.

## Private mirror hardening (#78)

Neither gap is exposed on the hosted endpoint, which serves the public dataset.

- Over the private mirror, loopback origins (`localhost`, `127.0.0.1`) must be
  listed in `IWAC_MCP_ALLOWED_ORIGINS` like any other. Public mode still accepts
  them without configuration.
- DuckDB's sandbox lists the seven subset directories instead of the whole
  cache directory, so a public instance can no longer reach a `private-full/`
  cache on the same machine.

## Tests (#75)

The worst-case token test's guard against empty results works again (it had
been off since v5.0.0), `get_sentiment_distribution` is measured with
`model: "all"`, and the stale-build check watches `manifest.json`.
