# v4.0.0: Semantic search without an API key

On 2026-10-13 every vector column in the IWAC dataset was regenerated with
[EmbeddingGemma 2](https://huggingface.co/google/embeddinggemma-2) (dataset
revision `d834ab71`). Earlier servers still encode queries with Gemini and rank
them against the new vectors, so their semantic search returns meaningless
rankings without any error. **Upgrade.** This release runs the corpus model
itself and refuses to rank across two vector spaces.

- **Local query encoder.** The `semantic_search_*` tools encode queries
  in-process with the same pinned ONNX export the corpus was built with: no API
  key, and query text never leaves the machine. The weights are downloaded once
  on first use (q8, ~350 MB; `IWAC_EMBEDDING_DTYPE=fp32` for the exact 1.1 GB
  graph) and checked against pinned SHA-256 digests. On 14 reference queries
  (French, English, Arabic, transliteration variants, acronyms), the Node
  encoder tokenizes exactly as the Python pipeline does and reaches cosine
  0.99994 (q8) and 1.000000 (fp32) to its vectors.
- **Semantic search is on by default**, in Claude Desktop and in the Docker
  image, which fetches the encoder at start-up. Turn it off with the
  **Semantic search** setting or `IWAC_SEMANTIC_SEARCH_ENABLED=false`.
- **Fails closed.** The `published-default` contract that let the model change
  through unnoticed is gone. Before ranking, the encoder must reproduce a
  reference probe vector, and each vector column must agree with anchor items
  measured on the corpus. A column from another model, or an older dataset
  revision pinned with `IWAC_DATASET_REVISION`, is refused with an error that
  says so.
- **`semantic_search_references`** (new) searches academic references by title
  + abstract across French and English. It covers the 442 references with an
  abstract.
- **Documents and references in the similarity tools.** `get_similar_items` and
  `get_semantic_map` accept `documents` (newly embedded) and read references'
  new `embedding_abstract` column; the retired `embedding_OCR` made both fail
  for references.
- **Scores recalibrated.** Cosines in the new space run high (unrelated articles
  ~0.7). `get_similar_items` now flags neighbours at 0.97, the upstream
  near-duplicate calibration (94% lexically confirmed), instead of the Gemini-era
  0.85; `scripts/reprint-candidates.mjs` defaults to 0.97 too.
- **Lighter publication results.** `semantic_search_publications` rows carry the
  first 600 characters of each table of contents instead of the whole table
  (median 6 to 12k characters), so a full page no longer runs to ~100k tokens.
  Its coverage is now 603 of 1,501 issues, including all of Islam Hebdo.

**Breaking changes.** Gemini support is removed, with `@google/genai`. The
`IWAC_GOOGLE_API_KEY` setting is gone, and `IWAC_EMBEDDING_PROVIDER=gemini`
is refused by name. `IWAC_EMBEDDING_MODEL` and `IWAC_EMBEDDING_DIMENSIONALITY`
have no defaults any more: when set, they only assert the corpus model.
`IWAC_EMBEDDING_PROVIDER=local` still posts to an OpenAI-compatible endpoint,
which must now pass the same probe check.

**Platforms.** The encoder runs on Windows x64 and ARM64 (with the Microsoft
Visual C++ 2015-2022 Redistributable), Apple-silicon macOS and Linux.
onnxruntime-node has no Intel-macOS build: there the semantic tools say they
cannot run, and every other tool works. The desktop bundles carry only their own
OS's onnxruntime binaries, without the DirectML and WebGPU libraries the CPU
encoder never loads.

The always-on tool footprint grows from 14,815 to 15,942 tokens, because the
four semantic tools are now listed by default.
