# v6.3.3: slimmer skill for Skills over MCP and sharper Tool Search discovery

A patch release focused on progressive disclosure and tool discovery on hosts
that natively support **Skills over MCP** (`io.modelcontextprotocol/skills`) and
**Tool Search** (`defer_loading` / `anthropic/alwaysLoad`). No tool or argument
is added or removed. The always-on footprint moves from 15,708 to 15,763 of
16,000 tokens (1,729 tokens upfront on hosts using Tool Search).

## Slimmer skill for native Skills over MCP

Now that Claude (Pro/Max/Ultra, Team opt-in) and Claude Code discover and load
the bundled `iwac-mcp` skill automatically over SEP-2640, every session pays for
`SKILL.md` on activation:

- `.agents/skills/iwac-mcp/SKILL.md` drops from **40.9 KB (289 lines) to
  18.0 KB (147 lines)** (−56%) by removing duplication with `references/` while
  preserving every operational rule, budget, citation format and bias constraint.
  The embedded 5-file skill bundle shrinks to 104.5 KB.
- The frontmatter `description` adds French collection terms (*Collection Islam
  Afrique de l'Ouest*, *CIAO*, *presse ouest-africaine*) and an explicit
  negative trigger steering Omeka S writes and Hugging Face pipeline work to
  `iwac-data` / `omeka-s-dev`.
- Stale version and file references (`v0.9.0+`, `mcpb/src/index.ts`) are cleaned
  up in `SKILL.md` and `references/tools-by-phase.md`, and `tools-by-phase.md`
  documents `explore_corpus`'s `link: true` whole-selection export option.

## Sharper Tool Search discovery

The server already marks only `search`, `fetch` and `get_collection_stats` with
`anthropic/alwaysLoad: true`, keeping the other 36 tools deferred on Tool Search
hosts (~1,729 tokens upfront instead of 15,763):

- `mcpb/src/instructions.ts` adds a profile-aware capability summary naming the
  deferred tool families (filtered subset search/reading, 6-model sentiment, LDA
  topics, co-occurrence, place map, lexical metrics and reprint similarity) while
  remaining within the 2,048-character limit across all 24 configuration modes.
- Five terse tool descriptions (`list_subjects`, `list_locations`,
  `list_persons`, `get_index_entry` and `get_newspaper_stats`) gain explicit
  English/French search keywords so BM25/regex Tool Search surfaces them
  reliably.
- `mcpb/test/token-budget.test.mjs` now prints the deferred Tool Search
  footprint alongside the full always-on footprint, and
  `mcpb/test/token-baseline.json` is updated accordingly.
