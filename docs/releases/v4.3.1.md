# v4.3.1: SQL lambdas ready for DuckDB 2.0

DuckDB 2.0 refuses the old arrow lambda (`x -> expr`) with a Binder Error. The
Dependabot bump to `@duckdb/node-api` 2.0.0-r.1 (#56) turned every CI job red
for that reason alone: the shared pipe-list filter behind most tools, the
embedding sanity checks in the semantic aggregates and the stress-fixture
script all used it.

- **New lambda syntax.** All six lambdas now use `lambda x: expr`, which the
  DuckDB 1.5.6 shipped in this release already accepts. Query results are
  unchanged.
- **Still on DuckDB 1.5.6.** This release does not include the 2.0 bump. It
  removes the known blocker so #56 can be judged on its own merits.
- **Housekeeping.** Dev-tooling updates (#57) and a newer
  `docker/login-action` in the release workflow (#55).

Tools, payloads and the dataset are unchanged.
